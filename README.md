# ربات تبلیغاتی Truck Part Trading

هر روز **دو پست** و برای هرکدام **یک استوری** می‌سازد و روی اینستاگرام، فیسبوک و تلگرام منتشر می‌کند.
عکس‌ها از پوشه `products/` برداشته می‌شوند و با پس‌زمینه، نورپردازی، سایه، شماره قطعه، دکمه و آدرس سایت آماده می‌شوند.

| پلتفرم | پست | استوری |
|---|---|---|
| اینستاگرام | ✅ | ✅ |
| فیسبوک (Page) | ✅ | ✅ |
| تلگرام (کانال) | ✅ | ❌ (API تلگرام برای کانال استوری ندارد) |

## ۱. نصب

نیاز: Python 3.10 به بالا.

```bash
pip install -r requirements.txt
cp .env.example .env        # ویندوز: copy .env.example .env
python main.py check
```

## ۲. تنظیمات سایت و ظاهر (`config.yaml`)

- `brand`: اسم، آدرس سایت، شماره تلفن / واتساپ / ایمیل (هرچه پر کنید روی عکس و کپشن می‌آید).
- لوگو: فایل PNG شفاف را با نام `assets/logo.png` بگذارید. اگر نباشد، حروف اول اسم برند (TPT) ساخته می‌شود.
- `schedule.timezone` و `schedule.posts`: ساعت دو پست روزانه.
- `categories`: اسم هر پوشه محصول. **این اسم‌ها را از روی شکل عکس‌ها حدس زده‌ام؛ حتما بازبینی کنید.**
- فونت: اگر فونت دلخواه دارید، `fonts/bold.ttf` و `fonts/regular.ttf` را بگذارید.

> آدرس سایت را از روی قالب‌هایتان `www.truckparttrading.com` گذاشته‌ام. شماره‌های تماس و اینستاگرام هم از قالب‌ها برداشته شده؛ اصلاحشان کنید اگر لازم است. من نتوانستم به خود سایت دسترسی بگیرم، پس متن کپشن‌ها عمومی است؛ توضیحات واقعی (تخفیف، ارسال و ...) را در `tsb/captions.py` اضافه کنید.

## ۳. قالب‌های پوستر و اطلاعات محصولات

سیزده قالب PSD شما به `templates/` تبدیل شده‌اند (لایه‌های ثابت = پس‌زمینه، لایه‌های متغیر = جای متن و عکس).
ربات این‌ها را از **اطلاعات محصولات شما** پر می‌کند: عکس کالا، کد، نام فارسی و انگلیسی، مشخصات فنی (قطرها، وزن، ضخامت، نوع نصب و ...)، تعداد، ابعاد بسته‌بندی و گرید.
جعبه‌ها، لوگوها، تماس و آیکن‌ها همان طراحی خودتان‌اند.

**قالب هر محصول** بر اساس دسته و **برند** انتخاب می‌شود (بخش `templates` در `config.yaml`):

| قالب | محصولات |
|---|---|
| abs / adj / bearing / shock | HUMMER (رینگ ABS، جغجغه، بلبرینگ، کمک فنر) |
| wega / wega_bolt | WEGA (کمک فنر کابین، پیچ چرخ) |
| afre_disc / afre_seal | AFRE (دیسک، کاسه نمد) |
| nok / kaan_seal | کاسه نمد NOK و KAAN |
| egd / kaan | لوازم کالیپر برند EGD FREN / KAAN |
| china | ORGINAL (قطعات کالیپر کامیون چینی و HOWO) |

محصولاتی که برندشان قالب ندارد (مثلا لنت، بوش، کیسه باد) با طرح خودکار پست می‌شوند.

**منبع اطلاعات**: `data/products_db.json` که از فایل‌های `attr/*.txt` و اکسل‌های شما ساخته شده. اگر اطلاعات عوض شد:
```bash
python tools/build_database.py /path/to/claude-product-data     # نیاز به: pip install openpyxl
```
برای اصلاح دستی یک محصول، `python main.py export-data` فایل `data/products.csv` را (پر شده با همان اطلاعات) می‌سازد؛ هر خانه‌ای که آنجا بنویسید روی پوستر همان محصول جایگزین می‌شود. `python main.py guide` نشان می‌دهد هر ستون کجای پوستر می‌نشیند.

> ⚠️ روی قالب‌ها ادعاهای برندی ثابت چاپ شده («Made in Turkey»، «Origin: IRAN»، «Genuine NOK Product»، «2 years warranty» ...). فقط محصولی را به قالب بدهید که با آن می‌خواند؛ انتخاب بر اساس برند همین کار را می‌کند. مقادیر مخصوص هر محصول (ابعاد بسته‌بندی، نوع کمک فنر، گرید پیچ) پاک و از اطلاعات محصول نوشته می‌شوند. جای خالی = «-».

```bash
python main.py preview --templates   # یک نمونه از هر قالب در output/preview/
python main.py check                 # چند محصول با کدام قالب پست می‌شود و چند محصول اطلاعات دارد
```

**نسبت تصویر**: پوسترها ۲:۳ هستند ولی فید اینستاگرام فقط ۴:۵ تا ۱.۹۱:۱ می‌پذیرد. برای اینستاگرام پوستر وسط یک بوم ۴:۵ با پس‌زمینه محو گذاشته می‌شود و استوری هم همین‌طور (داخل ناحیه امن). فیسبوک و تلگرام پوستر اصلی را کامل می‌گیرند.

**فونت**: برای عدد و کد از Roboto (همراه پروژه) و برای فارسی از DejaVu Sans (همراه پروژه) یا Tahoma ویندوز استفاده می‌شود. اگر فونت‌های اصلی قالب‌ها (Bahnschrift، Myriad Arabic) را دارید، با نام `fonts/cond.ttf` (کد و اعداد) و `fonts/fa.ttf` (فارسی) بگذارید.

## ۴. پیش‌نمایش بدون انتشار

```bash
python main.py preview --count 6
```
عکس‌ها در `output/preview/` ذخیره می‌شوند. اگر ظاهر یا اسم دسته‌ها را عوض کردید، دوباره اجرا کنید تا نتیجه را ببینید.

## ۵. اتصال به اینستاگرام، فیسبوک و تلگرام

ساده‌ترین راه، ویزارد اتصال است:

```bash
python main.py setup     # قدم‌به‌قدم می‌پرسد و توکن‌ها را فقط در .env همین کامپیوتر ذخیره می‌کند
python main.py test      # بررسی می‌کند هر اتصال واقعا کار می‌کند
```

ویزارد این کارها را خودکار انجام می‌دهد: تلگرام (بررسی توکن ربات و ادمین بودن در کانال)، فیسبوک و اینستاگرام (تبدیل توکن کوتاه‌مدت Graph API Explorer به توکن دائمی Page و پیدا کردن خودکار `IG_USER_ID`)، و Cloudinary (تست آپلود و لینک عمومی).
فقط این‌ها را باید خودتان آماده کنید: ساخت ربات در BotFather، ساخت App در developers.facebook.com، و ساخت Upload Preset در Cloudinary. جزئیاتش در همین بخش آمده است.
`python main.py test --send-test` یک پیام آزمایشی هم در کانال تلگرام می‌فرستد.

### راه دستی (اگر ویزارد را نمی‌خواهید)

### تلگرام (ساده‌ترین، اول این را راه بیندازید)
1. در تلگرام به `@BotFather` پیام بدهید، `/newbot` بزنید و توکن را در `TG_BOT_TOKEN` بگذارید.
2. ربات را در کانال خود **Admin** کنید (با اجازه ارسال پیام).
3. `TG_CHAT_ID` را برابر `@نام_کانال` بگذارید.

### فیسبوک
1. در developers.facebook.com یک App بسازید.
2. با Graph API Explorer یک توکن با دسترسی‌های `pages_manage_posts` و `pages_read_engagement` بگیرید و آن را به توکن بلندمدت Page تبدیل کنید.
3. `FB_PAGE_ID` و `FB_PAGE_TOKEN` را در `.env` بگذارید.

### اینستاگرام
1. حساب باید **Business یا Creator** و به یک Facebook Page وصل باشد.
2. دسترسی‌ها: `instagram_basic`، `instagram_content_publish`، `pages_show_list`، `pages_read_engagement`.
3. `IG_USER_ID` (شناسه حساب اینستاگرام) و `IG_ACCESS_TOKEN` (توکن بلندمدت) را در `.env` بگذارید.
4. تا وقتی App در حالت Development است و خودتان Admin/Tester هستید، انتشار روی حساب خودتان بدون بازبینی متا کار می‌کند.

### میزبانی عکس برای اینستاگرام
اینستاگرام عکس را فقط از یک **لینک عمومی** می‌گیرد و فقط JPEG قبول می‌کند (ربات خودش JPEG می‌سازد).
- ساده‌ترین راه: حساب رایگان Cloudinary بسازید، در Settings → Upload یک Upload Preset از نوع **Unsigned** بسازید و `CLOUDINARY_CLOUD_NAME` و `CLOUDINARY_UPLOAD_PRESET` را در `.env` بگذارید.
- راه دوم: `hosting.mode: static` و پوشه `output/` را روی سرور خودتان با یک آدرس عمومی سرو کنید و آن آدرس را در `public_base_url` بنویسید.

نسخه Graph API در `config.yaml` (`graph_api_version`) قابل تغییر است؛ اگر متا نسخه را منسوخ کرد آخرین نسخه را بگذارید.

## اجرا روی Render (بدون کامپیوتر روشن)

ربات به‌صورت **Cron Job** روی Render اجرا می‌شود و فقط سر ساعت‌های پست بالا می‌آید (`python main.py post --auto`).
چون دیسک Cron Job پایدار نیست، انتخاب محصول بر اساس تقویم است و به فایل ذخیره‌شده نیاز ندارد: هر شماره پست همیشه همان محصول را برمی‌دارد و تا همه عکس‌ها یک بار نمایش داده نشوند تکرار نمی‌شوند.

1. پروژه را روی یک ریپوی GitHub (ترجیحا Private) بگذارید:
   ```bash
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<user>/truck-social-bot.git
   git push -u origin main
   ```
2. در Render یک Cron Job با `render.yaml` یا از طریق Claude بسازید. ساعت اجرا در cron (UTC) باید با `schedule.posts` در `config.yaml` یکی باشد.
3. توکن‌ها را در Render → Environment وارد کنید (در `.env.example` اسم‌ها هست). `.env` هرگز در Git نمی‌رود.
4. در Render روی Cron Job دکمه «Trigger Run» را بزنید و لاگ را ببینید.

## ۶. تست و اجرا

```bash
python main.py post --dry-run                   # فقط عکس و کپشن می‌سازد
python main.py post --platforms telegram        # یک انتشار واقعی فقط روی تلگرام
python main.py post                             # انتشار واقعی روی همه
```

اجرای خودکار (یکی از این‌ها):
- `python main.py run` را روی یک سرور/کامپیوتر همیشه روشن اجرا کنید.
- یا هر ۱۰ دقیقه `python main.py tick` را با cron (لینوکس) یا Task Scheduler (ویندوز) اجرا کنید. هر اسلات فقط یک بار در روز منتشر می‌شود.

## ۷. رفتار ربات

- هر محصول تا وقتی همه حدود ۹۳۰ عکس یک بار نمایش داده نشده تکرار نمی‌شود و دسته‌ها به نوبت می‌آیند.
- اگر ربات سر ساعت روشن نبود، تا `grace_minutes` بعد هنوز پست می‌کند؛ اگر انتشار خطا داد، تا ۳ بار دوباره تلاش می‌کند.
- خطا در یک پلتفرم جلوی بقیه را نمی‌گیرد. نتیجه هر انتشار در `logs/published.jsonl` و لاگ کامل در `logs/bot.log` است.
- کپشن‌ها از چند قالب مختلف چرخشی ساخته می‌شوند تا پست‌ها کپی‌شده به نظر نرسند. کپشن هر پست در `output/<تاریخ>/…/captions.json` ذخیره می‌شود.

## ۸. نکات مهم

- عکس‌ها ۴۰۰ پیکسل هستند و برای پست بزرگ‌تر می‌شوند؛ ربات شارپ می‌کند ولی عکس‌های اصلی با کیفیت بالاتر نتیجه بهتری می‌دهند.
- روی بعضی عکس‌ها نام برندهای دیگر (WEGA، KNORR، KAAN، …) چاپ شده. اگر قطعات اصل آن برندها نیستند، در اسم دسته‌ها و کپشن‌ها ادعای «اصل» نکنید.
- لینک داخل کپشن اینستاگرام قابل کلیک نیست؛ آدرس سایت روی خود عکس و در کپشن نوشته می‌شود. لینک کلیکی فقط در بیو یا استیکر لینک (دستی) ممکن است.
- توکن‌ها را هرگز در جای عمومی نگذارید و `.env` را آپلود نکنید.
